# seer 小红书爬虫项目技术方案

## 1. 技术选型

| 类别 | 技术/库 | 版本 | 选型理由 |
|------|---------|------|----------|
| 开发语言 | Python | 3.11+ | 成熟稳定，生态丰富，适合爬虫开发 |
| 依赖管理 | uv | 最新 | 高性能、现代化的 Python 包管理工具 |
| 爬虫框架 | Playwright | 最新 | 强大的浏览器自动化工具，能很好处理动态渲染页面 |
| 数据解析 | BeautifulSoup4 + Playwright 选择器 | 最新 | 结合使用，提高解析效率和灵活性 |
| 数据存储 | JSON + 文件系统 | - | 元数据使用 JSON 格式便于后续模型处理，媒体资源直接存储为文件 |
| 日志记录 | Python logging 模块 | - | 标准库，功能完善，易于配置 |
| 测试框架 | pytest | 最新 | 主流 Python 测试框架，支持单元测试和集成测试 |
| 配置管理 | pydantic-settings | 最新 | 类型安全的配置管理库 |

## 2. 系统架构设计

### 2.1 模块划分

| 模块 | 功能描述 |
|------|----------|
| 爬虫模块 | 负责获取网页内容和媒体资源，实现反爬策略 |
| 解析模块 | 负责解析网页内容，提取有用信息 |
| 存储模块 | 负责将数据存储到本地 |
| 配置模块 | 负责管理项目配置 |
| 日志模块 | 负责记录系统运行日志 |
| 工具模块 | 提供通用工具函数 |

## 3. 核心功能实现

### 3.1 爬虫模块

- 使用 Playwright 模拟浏览器访问小红书网页
- 实现反爬策略：
  - 随机延迟请求
  - User-Agent 伪装
  - IP 代理支持
  - Cookie 管理
- 支持指定链接的定向爬取
- 支持爬取内容类型：
  - 文字信息
  - 图片资源
  - 视频资源
  - 评论区信息

### 3.2 解析模块

- 解析网页结构，提取 UP 主信息
- 提取发布内容的文字、图片 URL、视频 URL
- 提取评论区信息（评论者、评论内容等）
- 处理动态加载内容

### 3.3 存储模块

- 按 UP 主 ID 和日期组织目录结构
- 媒体资源下载到对应目录
- 元数据存储为 JSON 格式，包含：
  - 内容 ID
  - UP 主信息
  - 发布时间
  - 内容类型
  - 文字内容
  - 媒体资源列表
  - 评论列表

### 3.4 错误处理

- 网络错误重试机制
- 解析错误处理
- 存储错误处理
- 断点续爬支持

### 3.5 日志记录

- 记录系统运行状态
- 记录错误信息
- 记录爬取进度
- 支持不同日志级别配置
